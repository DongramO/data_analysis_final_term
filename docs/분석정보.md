## 핵심 발견 7가지

| # | 발견 | 근거 |
|---|------|------|
| 1 | **업종점수와 2030비중은 동시에 상승한다 (선후 관계 없음)** | Δ업종점수(t)→Δ2030비중(t+1): r=-0.117 n.s. / 동시 상관: r=0.394*** — "업종이 먼저"가 아니라 함께 온다 |

## 이동-소비 사분면 분석 — 유망 후보 발굴

> 스크립트: `analysis_quadrant_20.py` | 시각화: `image/gen20/07_quadrant_analysis.png`, `08_quadrant_timeseries.png`

### 분석 관점

**매출 = 이미 발생한 결과 / 이동 성장세 = 앞으로의 신호**

기존 분석에서 매출 기반 후보와 이동 기반 후보가 겹치지 않았던 이유가 바로 이것이다. 두 지표를 별도 축으로 분리하면 "현재는 덜 알려졌지만 20대가 몰려오는 중"인 지역을 포착할 수 있다.

```
X축 (현재 상태): 매출 활성도 점수
  = z(20대 매출 규모) + z(20대 매출 비중) + z(YoY 성장률)

Y축 (미래 신호): 이동 성장세 점수
  = z(장기증가율 2022→2024) + z(선형기울기) + z(최근급등 Q4→Q3 lag1 quarterly)

이동 신호 설계 원칙: 신흥 상권은 갑작스럽게 주목도가 올라가는 특성
→ 최근급등 = lag1 quarterly Q-o-Q (Q4 2024 vs Q3 2024): 연간 평균은 급등을 희석하므로 직전 분기 단독 비교
```

### 적용 임계치 (3단계)

| 단계 | 조건 | 목적 |
|------|------|------|
| ① | avg22 ≥ 3% | 2022 기저값이 너무 낮은 동 제거 (소폭 변화 → 폭등률 방지) |
| ② | OLS 기울기 > 0 | 5년 전체(2020Q1~2024Q4) 우상향 추세만 포함. 장기증가율(2022→2024)은 2022 코로나 반등 정점 효과로 사용 불가 |
| ③ | 직전 분기 lag 값 ≥ 5% | 직전 분기 기저값이 낮으면 최근급등 = 0(중립) 처리 |

| **지표 성격** | 결과 지표 (업종·소비패턴) | 선행 지표 (이동 증가세) |
| **신뢰도** | 높음 — 검증된 레퍼런스와 비교 | 보통 — 이동이 소비로 전환되는 보장 없음 |
| **타이밍** | 전환 초중기 포착 | 전환 이전 단계 포착 (더 이른 신호) |

### 교집합 — 두 기준 모두 충족 (가장 강한 후보)

| 행정동 | P35 순위 (유사도) | P41 순위 (성장세) | 해석 |
|--------|:----------------:|:----------------:|------|
| **보문동** | 7위 (0.601) | 12위 (0.12) | 성북구 소형 상권 — 업종 형성 중 + 이동 OLS 우상향 |

> 교집합 1개. 두 지표가 측정하는 단계 자체가 다르기 때문이며, 이것이 오히려 두 분석의 독립성을 보여준다.  
> **보문동** = 현재 상권 유사도(P35)와 이동 성장세(P41) 모두 확인 → 가장 신뢰도 높은 단일 후보.

- 의미: **지금 당장 주목해야 할 곳** — 이미 전환 궤도 진입
- 리스크: 이동 신호 없으면 업종 전환이 소비 폭발로 이어지지 않을 수 있음

## 핵심 지표 정의 (빠른 참조)

```
트렌드_대표_매출  = 금요일_매출 × 야간비중 + 토요일_매출(전체) + 일요일_매출(전체)
야간비중          = (17~21시 + 21~24시) / 전체 시간대
                   ※ 토·일은 야간 필터 없이 전체 포함 — 상권형은 낮/밤 모두 유동 높음
금요효과          = 금요일_매출 / 목요일_매출
주말집중도        = 주말 평균 생활인구 / 평일 평균 생활인구 (1.0 기준: 주말=평일)

업종점수          = (F&B카페+F&B식사+주류유흥+라이프스타일) / 총_매출
2030비중          = (20대+30대 매출) / 총_매출  ← 반드시 사후 검증 전용 (순환논리 방지)
```

> ~~복합점수 = zscore(업종점수) + zscore(시간점수)~~ **현재 미사용** — 복합점수로 선정한 레퍼런스를 복합점수로 검증하면 순환논리. 4개 독립 신호(S1~S4)로 대체.
