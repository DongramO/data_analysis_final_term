 분석 기준점 정리

  1. 트렌드 상권 정의 (Phase 7 확정)

  2030비중을 기준에서 완전 배제 — 순환논리 방지 원칙

  ┌───────────────┬─────────────────────────────────────────────────────────────────┐
  │   구성 요소   │                             계산식                              │
  ├───────────────┼─────────────────────────────────────────────────────────────────┤
  │ 업종점수      │ (F&B카페 + F&B식사 + 주류/유흥 + 라이프스타일) 매출 / 총매출    │
  ├───────────────┼─────────────────────────────────────────────────────────────────┤
  │ 시간점수      │ zscore(금요효과) + zscore(주말비중) + zscore(야간비중)          │
  ├───────────────┼─────────────────────────────────────────────────────────────────┤
  │ 복합점수      │ zscore(업종점수) + zscore(시간점수)                             │
  ├───────────────┼─────────────────────────────────────────────────────────────────┤
  │ 복합점수_분위 │ 해당 기간(연도/분기) 내 423개 동 상대 순위 (0=최하위, 1=최상위) │
  └───────────────┴─────────────────────────────────────────────────────────────────┘

  ▎ 검증: 2030비중을 전혀 쓰지 않았음에도 트렌드 상권의 2030비중이 일반 상권보다 +13.7pp 높음 → 정의가 실질을 반영

  3. 핵심 지표 정의 및 참고 수준

  ┌──────────────────┬────────────────────────────────────────────────────┬─────────────────────────────┐
  │       지표       │                       계산식                       │          참고 수준          │
  ├──────────────────┼────────────────────────────────────────────────────┼─────────────────────────────┤
  │ 트렌드_대표_매출 │ 금요일_매출 × 야간비중 + 토요일_매출 + 일요일_매출 │ —                           │
  ├──────────────────┼────────────────────────────────────────────────────┼─────────────────────────────┤
  │ 야간비중         │ (시간대_17~21 + 시간대_21~24) / 전체 시간대 합계   │ —                           │
  ├──────────────────┼────────────────────────────────────────────────────┼─────────────────────────────┤
  │ 트렌드매출_비중  │ 트렌드_대표_매출 / 총_매출                         │ 서울 전체 평균 25~28%       │
  ├──────────────────┼────────────────────────────────────────────────────┼─────────────────────────────┤
  │ 업종점수         │ 4개 카테고리 매출 합 / 총_매출                     │ 트렌드 상권 기준선 45~50%   │
  ├──────────────────┼────────────────────────────────────────────────────┼─────────────────────────────┤
  │ 금요효과         │ 금요일_매출 / 목요일_매출                          │ 트렌드 상권 평균 1.15~1.35  │
  ├──────────────────┼────────────────────────────────────────────────────┼─────────────────────────────┤
  │ 주말비중         │ (토+일) / 7일 합계                                 │ 균등 28.6%, 트렌드 30% 이상 │
  ├──────────────────┼────────────────────────────────────────────────────┼─────────────────────────────┤
  │ 2030비중         │ (연령대_20 + 연령대_30) / 총_매출                  │ —                           │
  └──────────────────┴────────────────────────────────────────────────────┴─────────────────────────────┘

  ▎ 금요효과에 목요일을 쓰는 이유: 월~목은 평일 패턴이 유사 → 목요일이 평일 기준값. 금요일이 목요일보다 높으면 주말 효과가 금요일부터 선행한다고 해석

  4. 2030비중 사용 원칙

  ▎ 트렌드 상권 정의(복합점수)에 포함하지 않는다.
  ▎ 반드시 사후 검증 또는 종속변수로만 사용.
  ▎ 정의에 넣으면 "2030이 많은 곳을 트렌드로 정의했더니 2030이 많더라"는 순환논리.

  5. 상권티어 분류 기준 (Phase 11 + Phase 13 수정 확정)

  ┌───────────────┬──────────────────────────────────────────────┬─────┐
  │     티어      │                     조건                     │ 수  │
  ├───────────────┼──────────────────────────────────────────────┼─────┤
  │ ① 레전드      │ 분위 ≥ 0.90 + R² ≥ 0.50 (꾸준히 최상위)      │ 21  │
  ├───────────────┼──────────────────────────────────────────────┼─────┤
  │ ② 라이징스타  │ 분위 ≥ 0.70 + 모멘텀 상위 20%                │ 25  │
  ├───────────────┼──────────────────────────────────────────────┼─────┤
  │ ③ 급성장 신흥 │ 분위 0.50~0.90 + 모멘텀 상위 10%             │ 18  │
  ├───────────────┼──────────────────────────────────────────────┼─────┤
  │ ④ 잠재 후보   │ 분위 0.40~0.70 + 양의 모멘텀                 │ 41  │
  ├───────────────┼──────────────────────────────────────────────┼─────┤
  │ ⑤ 성숙·정체   │ 분위 ≥ 0.70 + ①②③⑥ 조건 미충족 (모멘텀 무관) │ 81  │
  ├───────────────┼──────────────────────────────────────────────┼─────┤
  │ ⑥ 쇠퇴 주의   │ 2020 상위 30% → 2024 하위 50%                │  9  │
  ├───────────────┼──────────────────────────────────────────────┼─────┤
  │ ⑦ 일반        │ 나머지                                       │ 228 │
  └───────────────┴──────────────────────────────────────────────┴─────┘

  ▎ 수정 원칙 (Phase 13): 분위 ≥ 0.70인 행정동이 ⑦일반으로 낙하하는 경우 완전 제거.
  ▎ ⑤성숙·정체를 ①②③⑥ 이후 catch-all로 설계. 기준은 423개 전체에 동일 적용.

  ▎ 모멘텀 = 복합점수_분위(2024) − 복합점수_분위(2020)

  ▎ 정의에 넣으면 "2030이 많은 곳을 트렌드로 정의했더니 2030이 많더라"는 순환논리.

  6. 복합점수 비교 시 주의사항

  ▎ 복합점수는 기간 내 표준화 (연간 버전: 연도 내, 분기 버전: 분기 내)
  ▎ → 연도 간 / 분기 간 절댓값 직접 비교 불가. 분위(rank) 비교만 유효.

  7. 네이버 트렌드 사용 원칙 (Phase 8·9 확정)

  ▎ 네이버 검색량 ≠ 트렌드 소비 행동
  ▎ - 검색량: 인지도·관심도·이슈 반응 측정
  ▎ - 복합점수: 실제 방문 소비 행동 측정
  ▎ → 차세대 상권 예측에 네이버 단독 사용은 오도 위험. 매출 복합점수와 반드시 병행.
