## 0. 용어 사전 (Glossary)

본 문서에서 반복적으로 등장하는 약어·축약 용어를 명시한다.

### 0.1 시계열·통계 용어

| 용어 | 풀이 | 정의 |
| --- | --- | --- |
| **QoQ** | Quarter-over-Quarter | 전 분기 대비 증가율 (예: 2024Q2 vs 2024Q1) |
| **YoY** | Year-over-Year | 전년 동기 대비 증가율 (예: 2024Q2 vs 2023Q2) |
| **lag0** | 동시기 (lag = 0 분기) | 같은 분기의 두 지표 간 상관 |
| **lag1** | 1분기 지연 | 한 지표가 다른 지표보다 1분기 앞서는 관계 (예: 이동(t) vs 소비(t+1)) |
| **lag2** | 2분기 지연 | 2분기 시차 관계 |
| **r** | Pearson 상관계수 | -1 ~ +1 범위, 0.3 이상이면 약한 양의 상관 |
| **n.s.** | not significant | 통계적 유의성 없음 (p ≥ 0.05) |
| **z-score** | 표준화 점수 | (값 - 평균) / 표준편차 |

### 0.2 분석 임계치·필터 용어

| 용어 | 풀이 | 정의 |
| --- | --- | --- |
| **avg22** | 2022년 평균 (average of 2022) | 행정동의 2022년 20대 매출 비중 평균값. 기저효과 동을 거르는 필터로 사용 |
| **avg22 ≥ 3%** | 2022년 20대 매출 비중 3% 이상 | 절대량이 너무 작은 행정동을 후보군에서 제외하는 임계치 |
| **상위 30%** | 상위 분위수 | 423개 동 중 지표값 상위 30%에 해당하는 임계 |

### 0.3 주요 분석 단계·파일 용어

| 용어 | 풀이 |
| --- | --- |
| **궤적 유사도 분석** | 코사인 유사도 기반 후보 도출 분석 단계 |
| **이동-소비 사분면 분석** | 4분면 분석 기반 후보 도출 단계 |

| **Tier 1~3** | 두 분석 방법론 교차 검증 결과 등급 |

## 1. 연구 배경 및 가설

### 1.1 연구 배경

- 분석 기간: 2020년 ~ 2024년 (분기 단위)
- 분석 대상: 서울시 423개 행정동
- 목표: 현재 트렌드 상권의 활성화 패턴을 **20대의 이동과 소비** 양축에서 분석하여, 차세대 트렌드 상권 후보 행정동 도출

### 1.2 핵심 가설 (20대의 이동 + 소비 양축)

> **H1 (이동)**: 차세대 트렌드 상권은 활성화 이전 단계에서 **20대 유동인구 유입**이 선행적으로 증가한다. 특히 금요 야간·주말 시간대의 20대 유입이 핵심 신호이다.

> **H2 (소비)**: 20대 유입 이후 또는 동시기에 **20대 매출 비중**과 **트렌드 업종(카페·식사·주류·생활쇼핑) 매출**이 증가한다.

> **H3 (이동·소비 결합)**: 20대의 이동과 소비는 **lag0 또는 lag1**(동시 또는 1분기 시차)로 함께 움직이며, 임대료 상승은 이 두 신호 이후 **약 4분기(lag4) 뒤** 결과로 나타난다.

> **H4 (변화율 우위)**: 변화율(QoQ·YoY)이 절대량보다 차세대 상권 식별에 더 유효하다. (KT 데이터의 20대 편향 보정 차원)

📌 **[클로드 코드 작업 - 가설 검증용 핵심 수치]**
- 레퍼런스 16개 동에서 **20대 유입 증가 시점**과 **20대 매출 비중 증가 시점**의 시차(분기 단위) 측정
- 두 시점의 상관계수 산출: **lag0 / lag1 / lag2 분기별** Pearson r
- 임대료 상승 시점과의 시차: **lag0 / lag2 / lag4** 분기별 측정 (68개 상권 한정)
- 출력: `causal_lag_analysis.csv` (행: lag 구간 / 열: r값, p-value, 유의성)

## 4. 후보 지역 도출 — 두 가지 분석 방향

본 연구는 두 분석 방향을 병행한다. 같은 목표이나 **상권 생애주기상 측정 단계가 다르다**.

### 4.1 궤적 유사도 분석 — 코사인 유사도

- **질문**: 어떤 동이 레퍼런스 상권 패턴과 닮았는가?
- **방법**: 레퍼런스 16개 동의 **이동·소비 결합 궤적**을 벡터화 → 전체 동 대상 코사인 유사도 → 4개 독립 신호로 교차 검증
- **포착 단계**: 중기~성숙 단계
- **대표 발굴**: 청파동(0.909), 후암동(0.659), 연희동(0.574)

> **현행 수치 (신규 레퍼런스 4개 기준)**: `report/data/phase35_candidates_top15_v3.csv` — 1순위 숭인2동(0.944), 신당5동(0.930) 등. 상세는 `report/최종보고서_v6_데이터_조합.md`.

📌 **[클로드 코드 작업 - 궤적 유사도 분석 산출]**

- 4개 독립 신호 충족 여부 컬럼 추가

### 4.2 이동-소비 사분면 분석 — 4분면 분석

- **질문**: 어떤 동이 이동 신호상 곧 뜰 것인가?
- **방법**:
  - X축 (현재 상태 - 소비 기반): 매출 활성도 = z(20대 매출 규모) + z(20대 매출 비중) + z(YoY 성장률)
  - Y축 (미래 신호 - 이동 기반): 이동 성장세 = z(장기증가율) + z(선형기울기) + z(최근급등)
  - 유망 후보 = 2사분면 (저활성도 × 고성장세) + **avg22 ≥ 3% 임계치 필터링**
- **포착 단계**: 초기 신호 단계
- **대표 발굴**: 북아현동(5.24), 이촌2동(4.19), 창신3동(3.25)

📌 **[클로드 코드 작업 - 이동-소비 사분면 분석 산출]**

- 누락 동(주말집중도 미측정) 보강 필요

### 4.3 두 방법 비교 요약

| 항목 | 궤적 유사도 분석 | 이동-소비 사분면 분석 |
| --- | --- | --- |

## 7. 결론 및 향후 과제

### 7.1 핵심 인사이트

- 트렌드 상권은 **20대 이동 → 20대 소비** 신호가 lag0~lag1로 동반 증가
- 임대료는 두 신호 이후 **약 lag4(4분기) 뒤** 결과로 따라옴
- 절대치 낮은 지역은 avg22 ≥ 3% 필터링 필수
- 단일 방법론은 불완전 — 혼합 활용과 주말집중도 후처리가 신뢰도의 핵심

### 7.2 향후 과제

| 우선순위 | 과제 |
| --- | --- |
| ★★★ | 청파동·후암동·연희동 주말집중도 추세 모니터링 (주거형→상권형 진입 시점이 전환 확정 신호) |
| ★★★ | Tier 1 (교집합) 후보 심층 분석 |
| ★★★ | 레퍼런스 16개 동 정보 표(3.2) 완성 및 외부 자료 검증(6.3) |
| ★★ | 송파1동·서초2동 등 주말집중도 미측정 동 오피스 여부 검증 |
| ★★ | 성수동 20대 이탈 후 행선지 추적 |
| ★ | 통신 3사 데이터 통합, 월·주 단위 데이터 확보 |

📌 **[클로드 코드 작업 - 우선 처리 항목]**
