# 서울시 트렌드 상권 분析

> "2030세대가 먼저 이동하는 곳이 다음 트렌드 상권이 된다"  
> 서울시 423개 행정동 × 2020~2024년(5개년) 데이터로 차세대 트렌드 상권 후보군을 발굴한 프로젝트입니다.

분析 흐름 전체 기록은 [`ANALYSIS_LOG.md`](ANALYSIS_LOG.md)를 참고하세요.

---

## 핵심 지표 정의

### 트렌드_대표_매출

```
= 금요일_매출_금액 × 야간비중 + 토요일_매출_금액 + 일요일_매출_금액

야간비중 = (시간대_17~21_매출_금액 + 시간대_21~24_매출_금액) / 전체 시간대 매출 합계
```

"금요일 저녁 퇴근 후 ~ 주말" 구간의 소비 추정액. 트렌드 상권의 핵심 활동 시간대.

### 트렌드매출_비중

```
= 트렌드_대표_매출 / 총_매출
```

높을수록 외부 방문객 중심의 주말형 소비 상권. 서울 전체 평균 약 25~28%.

### 업종점수

```
= (F&B카페 + F&B식사 + 주류/유흥 + 라이프스타일) 매출 합계 / 총_매출
```

포함 업종: 커피·음료, 제과점, 한식·일식·양식·중식·분식·패스트푸드·치킨전문점, 호프·간이주점, 노래방, 일반의류, 편의점, 애완동물, 화초, 인테리어  
트렌드 상권 기준선 약 45~50% 이상.

### 금요효과

```
= 금요일_매출_금액 / 목요일_매출_금액
```

1.0 이상이면 금요일부터 외부 방문객 유입 시작 → 트렌드 상권 특성.  
트렌드 상권 평균 약 1.15~1.35.

### 주말비중

```
= (토요일_매출_금액 + 일요일_매출_금액) / 7일 매출 합계
```

균등 기준 28.6%, 서울 전체 평균 22~24%, 트렌드 상권 30% 이상.

### 2030비중

```
= (연령대_20_매출_금액 + 연령대_30_매출_금액) / 총_매출
```

> **주의**: 트렌드 상권 정의(복합점수)에 포함하지 않는다. 반드시 사후 검증 또는 종속변수로만 사용.

### 복합점수 / 복합점수_분위

```
복합점수   = zscore(업종점수) + zscore(시간점수)
시간점수   = zscore(금요효과) + zscore(주말비중) + zscore(야간비중)

복합점수_분위: 해당 연도 423개 행정동 내 상대적 위치 (0=최하위, 1=최상위)
```

연도 내 표준화이므로 연도 간 절댓값 비교 불가. 분위(rank) 비교는 가능.

### 상권티어 (6단계)

| 티어 | 조건 | 의미 |
|------|------|------|
| ① 레전드 | 분위 ≥ 0.90 + 추세 R² ≥ 0.50 | 꾸준히 최상위 유지 |
| ② 라이징스타 | 분위 ≥ 0.70 + 모멘텀 상위 20% | 상위권에서 계속 성장 |
| ③ 급성장 신흥 | 분위 0.50~0.90 + 모멘텀 상위 10% | 중간에서 빠르게 부상 |
| ④ 잠재 후보 | 분위 0.40~0.70 + 양의 모멘텀 | 주목할 예비 트렌드 상권 |
| ⑤ 성숙·정체 | 분위 ≥ 0.70 + ①②③⑥ 조건 미충족 | 상위권 전부 |
| ⑥ 쇠퇴 주의 | 2020 상위 30% → 2024 하위 50% | 뚜렷한 하락 추세 |

모멘텀 = 복합점수_분위(2024) - 복합점수_분위(2020)

## 주말 필터 원칙

모든 유입(이동) 및 매출 분析은 주말 데이터 기준.

- **이동**: `data/main_data/분기별_주말유입인구.csv` — 금요일 저녁 + 토요일 + 일요일 이동인구만 포함
- **매출**: `토요일_매출_금액 + 일요일_매출_금액` 또는 `트렌드_대표_매출` 사용

> 데이터 한계: 연령대 × 요일 교차 데이터 없음. "주말에 20대가 얼마 썼는지"는 계산 불가.  
> 세대별 소비 비중(전체 주 기준)과 세대별 유입 비중(주말 기준)을 혼용하지 않도록 주의.
