# 서울시 트렌드 상권 분析

**"2030세대가 먼저 이동하는 곳이 다음 트렌드 상권이 된다"**

서울시 423개 행정동 × 2020~2024년(5개년) 데이터를 활용해 이 가설을 검증하고, 현재 부상 직전인 차세대 상권 후보군을 발굴한 프로젝트입니다.

---

## 핵심 지표 정의

### 트렌드_대표_매출
```
= 금요일_매출_금액 × 야간비중 + 토요일_매출_금액 + 일요일_매출_금액

야간비중 = (시간대_17~21_매출 + 시간대_21~24_매출) / 전체 시간대 매출
```
"금요일 저녁 ~ 주말" 소비 추정액. 트렌드 상권의 핵심 활동 시간대를 포착하는 지표.

### 트렌드매출_비중
```
= 트렌드_대표_매출 / 총_매출
```
높을수록 외부 방문객 중심의 주말형 소비 상권. 서울 전체 평균 약 25~28%.

### 업종점수
```
= (F&B카페 + F&B식사 + 주류/유흥 + 라이프스타일) 매출 / 총_매출
```
포함 업종: 커피·음료, 제과점, 한식/일식/양식/중식/분식/패스트푸드/치킨, 호프·간이주점, 노래방, 일반의류, 편의점, 애완동물, 화초, 인테리어  
트렌드 상권 기준선 약 45~50% 이상.

### 금요효과
```
= 금요일_매출 / 목요일_매출
```
1.0 이상이면 금요일부터 외부 유입 시작 → 트렌드 상권 신호. 트렌드 상권 평균 약 1.15~1.35.

### 주말비중
```
= (토요일_매출 + 일요일_매출) / 7일 매출 합계
```
균등 기준 28.6%, 서울 전체 평균 22~24%, 트렌드 상권 30% 이상.

### 2030비중
```
= (연령대_20_매출 + 연령대_30_매출) / 총_매출
```
> **주의**: 트렌드 상권 정의에 포함하지 않는다. 정의에 넣으면 "2030이 많은 곳을 트렌드 상권으로 정의했더니 2030이 많더라"는 순환논리가 된다. 반드시 사후 검증 또는 종속변수로만 사용.

### 복합점수 / 복합점수_분위
```
복합점수 = zscore(업종점수) + zscore(시간점수)
시간점수 = zscore(금요효과) + zscore(주말비중) + zscore(야간비중)

복합점수_분위: 해당 연도 423개 행정동 내 상대적 위치 (0=최하위, 1=최상위)
```
연도 내 표준화이므로 연도 간 절댓값 비교 불가. 분위(rank) 비교는 가능.

### 주말집중도 (상권 유형 구분)
```
주말집중도 = 주말 평균 생활인구 / 평일 평균 생활인구
```

| 구역 유형 | 주말집중도 | 특징 |
|----------|:---------:|------|
| 오피스형 | < 0.80 | 역삼1동(0.652) — 2030이동 높아도 직장인, 상권 전환 신호 아님 |
| 혼합형 | 0.80~0.95 | 서초4동(0.845) — 오피스+거주 혼재 |
| 주거형 | 0.95~1.10 | 청파동(0.963) — 전환 후보 다수 포함 |
| 상권형 | > 1.10 | 이태원1동(1.225) — 주말에 외부인 급증 |

## 주말 필터 원칙

모든 이동·매출 분析은 주말 데이터 기준.

- **이동**: `분기별_주말유입인구.csv` — 금요일 저녁 + 토요일 + 일요일 이동인구만 포함
- **매출**: `토요일_매출 + 일요일_매출` 또는 `트렌드_대표_매출` 사용. 총_매출을 기준으로 쓰는 것은 주말 기준이 아님

> **데이터 한계**: 연령대 × 요일 교차 데이터 없음. "주말에 20대가 얼마 썼는지"는 계산 불가.  
> 세대별 소비 비중(전체 주 기준)과 세대별 유입 비중(주말 기준)을 혼용하지 않도록 주의.

## 핵심 발견

| # | 발견 | 근거 |
|---|------|------|
| 1 | **2030 유입 후 1년 뒤 임대료 상승** | Δ2030비중(t)→Δ임대료(t+1): r=0.219\*\* / 동시: r=0.125(n.s.) — 임대료는 원인이 아니라 결과 |
| 2 | **업종점수와 2030비중은 동시에 상승 (선후 관계 없음)** | 동시 상관 r=0.394\*\*\* / 1분기 선행 r=-0.117(n.s.) — "업종이 먼저"가 아니라 함께 온다 |
| 3 | **오피스형 2030과 여가형 2030은 주말집중도로 구분** | 역삼1동 0.652(직장인) vs 이태원1동 1.225(방문객) — 2030이동 비율만으로는 구분 불가 |
| 4 | **성수동은 동(洞)마다 생애주기가 다름** | 성수1가1동 2030비율 2022년 고점 후 하락 / 성수2가1동 2024년에도 43.0% 상승 |
| 5 | **청파동 궤적 유사도 1위(0.909)지만 아직 전환 초기** | 카페 업종 선점, 임대료 2023→2024 +29.5% 급등 — 상권화 직전 단계 |

423개 행정동 분기별 피처(96개)로 상권 상승/유지/하락 3분류. Optuna 100 trial 최적화.

| 구분 | Macro F1 |
|------|:--------:|
| 기존 모델 | 0.5383 |
| Optuna 최적화 | **0.5807** |

> 3-class 균등 랜덤 기준 F1 = 0.333. 피처 중요도 1위: 금요효과 / 3위: 2030소비_비중_lag1
