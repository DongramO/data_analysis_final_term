## 프로젝트 개요

### 배경

트렌드 상권은 단기간에 부상했다가 과열·젠트리피케이션을 거쳐 쇠퇴하는 주기를 반복합니다. 이 프로젝트는 **다음 트렌드 상권이 어디인지** 사전에 예측할 수 있는 신호를 찾는 것을 목적으로 합니다.

핵심 가설은 **20대(또는 2030세대)의 이동 패턴이 소비 전환보다 선행**한다는 것입니다. 이동 인구가 먼저 늘어난 행정동에서 6~12개월 후 상권 활성화가 뒤따르는 패턴을 실증 데이터로 검증했습니다.

### 분석 범위

| 항목 | 내용 |
|------|------|
| 대상 지역 | 서울시 423개 행정동 |

## 분석 방법론

### 핵심 지표 정의

```
트렌드_대표_매출 = 금요일_매출 × 야간비중 + 토요일_매출 + 일요일_매출
야간비중         = (17~21시 + 21~24시 매출) / 전체 시간대 매출

금요효과         = 금요일_매출 / 목요일_매출  (1.0 이상 = 주말 유동 선행 신호)
주말집중도       = 주말 평균 생활인구 / 평일 평균 생활인구

업종점수         = (F&B카페 + F&B식사 + 주류유흥 + 라이프스타일) / 총_매출
2030비중         = (20대 + 30대 매출) / 총_매출  ← 반드시 사후 검증 전용 (순환논리 방지)
```

### 상권 유형 분류 (주말집중도 기준)

| 구역 유형 | 주말집중도 | 대표 행정동 | 특징 |
|----------|:---------:|-----------|------|
| 오피스형 | < 0.80 | 역삼1동(0.652) | 주말에 사람 급감. 2030이동 높아도 직장인 |
| 혼합형 | 0.80 ~ 0.95 | 서초4동(0.845) | 오피스+거주 혼재 |
| 주거형 | 0.95 ~ 1.10 | 청파동(0.963), 연남동(1.075) | 전환 후보 다수 포함 |
| 상권형 | > 1.10 | 이태원1동(1.225) | 주말에 외부인 급증 |

### 상권티어 분류 (6단계)

| 티어 | 조건 |
|------|------|
| ① 레전드 | 분위 ≥ 0.90 + 추세 R² ≥ 0.50 |
| ② 라이징스타 | 분위 ≥ 0.70 + 모멘텀 상위 20% |
| ③ 급성장 신흥 | 분위 0.50~0.90 + 모멘텀 상위 10% |
| ④ 잠재 후보 | 분위 0.40~0.70 + 양의 모멘텀 |
| ⑤ 성숙·정체 | 분위 ≥ 0.70 (①②③⑥ 외) |
| ⑥ 쇠퇴 주의 | 2020 상위 30% → 2024 하위 50% |

### 4개 독립 신호 파이프라인

순환논리를 방지하기 위해 **2030 데이터를 정의에서 제외**하고, 아래 4가지 독립 신호로 전환 레퍼런스를 선별했습니다.

| 신호 | 기준 | 의미 |
|------|------|------|
| S1 업종 전환 | 업종점수 ≥ 0.50 | 트렌드형 업종 구성 비율 |
| S2 2030 소비 | 2030비중 ≥ 0.35 | 사후 검증용 소비 지표 |
| S3 임대료 | 전년 대비 상승 | 상권화 후행 신호 |
| S4 블로그 | 언급량 급등 | 외부 인지도 확산 신호 |

### 이동-소비 사분면 분석 (Phase 41~42)

```
X축 (현재 상태): 매출 활성도 = z(20대 매출 규모) + z(20대 매출 비중) + z(YoY 성장률)
Y축 (미래 신호): 이동 성장세 = z(장기증가율 2022→2024) + z(선형기울기) + z(최근급등 2023→2024)
```

사분면 2(저활성도 × 고성장세) = **가장 유망한 신흥 후보**, 총 116개 행정동

## 참고 사항

- **2030비중은 정의에 포함하지 않음**: 트렌드 상권 정의에 2030비중을 넣으면 "2030이 많은 곳을 트렌드 상권으로 정의했더니 2030이 많더라"는 순환논리가 됩니다. 반드시 사후 검증 또는 종속변수로만 사용합니다.
- **복합점수는 연도 내 표준화**: 연도 간 절댓값 비교는 불가하며, 분위(rank) 비교만 유효합니다.
- **유동인구 데이터**: `분기별_주말유입인구.csv`를 사용합니다. `population_quarterly.csv`(생활인구 전수)는 주중 평일 직장인을 포함하므로 트렌드 분석 기준에 부적합합니다.
